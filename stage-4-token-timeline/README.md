# Token Timeline — Stage 4

Press Space or click Pulse Timeline to earn Chronons. Repair six eras, buy Clock Drones, and fill the Paradox meter for a fourfold Time Rush. Rewind a mature timeline to collect permanent Echoes. Win by owning 40 Echoes, six Clock Drones, and two Stability ranks in every era, then restore the Prime Timeline.

Save data is local to this stage. The root repository build publishes this game at `/stage-4/`.
