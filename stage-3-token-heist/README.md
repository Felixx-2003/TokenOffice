# Token Heist

Stage 3 of the incremental-game series. Assemble ten AI specialists, run heists, trigger Perfect Heists, upgrade gadgets and disguises, and escape with permanent Master Blueprints.

Run `npm run dev:stage3` from the repository root to play locally. The combined production build publishes Token Heist at `/stage-3/` with a save key separate from Stages 1 and 2.
