# Token Circus

Stage 2 of the incremental-game series. Crack the Prompt Whip, recruit ten AI performers, upgrade their tricks and costumes, trigger Standing Ovations, and end successful shows for permanent Golden Tickets.

## Play locally

1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install` from the repository root.
3. Run `npm run dev:stage2` and open the local address Vite prints.

Run `npm run build` from the repository root to create the combined Cloudflare bundle. Token Circus is published at `/stage-2/` and stores progress independently from Token Office.
