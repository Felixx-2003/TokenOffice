# Signal Foundry

Stage 2 of the incremental-game series. Tune a signal core, build a deep-space relay fleet, trigger Resonance surges, and Fold mature runs into permanent Echo multipliers. Progress saves in this browser and includes up to eight hours of offline production.

## Play locally

1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install` (`npm.cmd install` in Windows PowerShell).
3. Run `npm run dev` (`npm.cmd run dev` in Windows PowerShell) and open the local address Vite prints.

Run `npm run build` to create the production bundle in `dist/`.
